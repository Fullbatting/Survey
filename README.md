# Survey Desk — Local MVP

관리자가 설문을 만들고 공개 링크를 공유해 응답을 수집하며, 통계·개별 응답·CSV를 확인할 수 있는 로컬 우선 MVP입니다.

## 1. 요구사항

- Node.js 20 이상
- 설치할 npm 패키지 없음 (Node.js 기본 모듈만 사용, QR 생성 라이브러리 `qrcode-generator`는 `public/vendor/`에 포함)
- 인터넷 연결 없이도 로컬 실행 가능

## 2. 실행 (Windows)

1. Node.js LTS를 설치합니다: https://nodejs.org/
2. GitHub 저장소 페이지에서 **Code → Download ZIP**으로 압축파일을 받습니다.
3. 압축파일을 원하는 폴더에 풉니다.
4. (권장) 압축을 푼 폴더의 `runserver.bat`을 메모장으로 열어 상단 설정의 `ADMIN_PASSWORD` 값을 충분히 긴 비밀번호로 바꾸고 저장합니다.
5. `runserver.bat`을 더블클릭해 서버를 실행합니다. 창을 닫거나 `Ctrl+C`를 누르면 서버가 종료됩니다.
6. 브라우저에서 `http://127.0.0.1:3000`에 접속합니다.
7. `runserver.bat`에 지정한 관리자 아이디/비밀번호로 로그인합니다.

기본값으로 실행할 경우 아이디는 `admin`, 비밀번호는 `change-this-password`입니다. **로컬 시험 전이라도 비밀번호를 변경하는 것을 권장합니다.**

인터넷에서 받은 파일이라 Windows 보안 경고가 표시될 수 있습니다. 이 경우 **추가 정보 → 실행**을 선택합니다.

## 3. 같은 네트워크에서 휴대폰/다른 PC로 시험하기

서버를 종료하고 `runserver.bat`의 `HOST` 값을 `0.0.0.0`으로 바꾼 뒤 다시 실행합니다.

서버가 PC의 내부 IPv4 주소를 자동으로 찾아 설문 링크와 QR 코드에 사용합니다(대시보드 상단 **공유 주소**에 표시). 같은 Wi-Fi의 휴대폰으로 QR을 스캔하거나 링크를 열면 됩니다. 처음 실행할 때 Windows 방화벽 허용 창이 뜨면 **개인 네트워크**를 허용하세요.

- `HOST`가 `127.0.0.1`(기본값)이면 링크·QR은 서버 PC에서만 열립니다.
- PC에 VPN·가상 네트워크 어댑터가 있어 다른 주소가 잡히면, `HOST`에 Wi-Fi의 IPv4 주소(예: `192.168.0.12`)를 직접 적으세요.

**주의:** 이 MVP는 HTTPS, CSRF 방어, 영구 세션 저장, 요청 속도 제한, 다중 관리자, 감사 로그를 완비한 상용 서비스가 아닙니다. 포트 포워딩이나 인터넷 전체 공개를 하지 마세요. LAN 시험도 신뢰할 수 있는 네트워크에서만 하세요.

## 4. 현재 기능

- 관리자 로그인 (프로세스 메모리 세션, HttpOnly/SameSite 쿠키)
- 설문 생성, 제목·설명 편집, 질문 편집(순서 이동·복제·삭제), 응답자 화면 미리보기, 게시/종료
- 단답형, 장문형, 객관식, 복수 선택, 드롭다운, 점수형(1~5)
- 설문별 무작위 공개 링크와 QR 코드 (링크 복사, QR 이미지 PNG 저장)
- 비로그인 응답 제출 및 필수 항목 검증
- 전체 설문/응답 대시보드
- 질문별 집계 (선택지별 응답 수·비율, 점수형 평균, 주관식 최근 응답)
- 개별 응답 조회 (검색, 이전/다음 이동)
- CSV 내보내기 (엑셀 수식 실행 방지 처리)
- 로컬 JSON 데이터 파일

## 5. 데이터와 백업

모든 데이터는 `data/db.json`에 저장됩니다. 서버를 중지한 뒤 파일을 다른 위치로 복사해 백업하세요. 복구할 때는 서버를 중지하고 백업 파일을 `data/db.json`으로 되돌립니다.

새 버전의 압축파일을 받아 다른 폴더에 풀었다면, 기존 폴더의 `data` 폴더를 새 폴더로 복사해야 기존 설문과 응답이 유지됩니다.

설문 삭제는 해당 설문의 응답까지 삭제합니다. 삭제 전에 백업하세요.

## 6. MVP 제한사항

- 설문에 응답이 접수된 뒤에는 질문 구조를 잠급니다. 제목·설명은 수정할 수 있습니다. 질문 버전 관리는 다음 개발 단계에서 구현해야 합니다.
- 동일 응답자의 중복 제출을 완벽하게 막지 않습니다. 로그인 없는 공개 설문에서 강한 중복 방지는 별도 설계가 필요합니다.
- 현재 세션은 서버 재시작 시 만료됩니다.
- JSON 파일 저장은 동시 쓰기·대량 응답에 적합하지 않습니다. 외부 공개 운영 전에는 트랜잭션이 있는 데이터베이스로 교체해야 합니다.
- 비밀번호 변경은 실행 환경변수로 관리합니다.
- 통계는 선택형 문항 중심이며 주관식은 개별 원문에서 확인합니다.
