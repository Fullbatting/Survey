# Survey Desk — Local MVP

관리자가 설문을 만들고 공개 링크를 공유해 응답을 수집하며, 통계·개별 응답·CSV를 확인할 수 있는 로컬 우선 MVP입니다.

## 1. 요구사항

- Node.js 20 이상
- 설치할 npm 패키지 없음 (Node.js 기본 모듈만 사용, QR 생성 라이브러리 `qrcode-generator`는 `public/vendor/`에 포함)
- 인터넷 연결 없이도 로컬 실행 가능

## 2. 실행 (Windows)

1. Node.js LTS를 설치합니다: https://nodejs.org/
2. GitHub 저장소 페이지에서 **Code → Download ZIP**으로 압축파일을 받습니다.
3. 압축파일을 원하는 폴더에 풉니다.
4. **(필수)** 압축을 푼 폴더의 `runserver.bat`을 메모장으로 열어 상단 설정의 `ADMIN_PASSWORD` 값을 충분히 긴 비밀번호로 바꾸고 저장합니다. 기본 비밀번호 그대로면 서버가 시작되지 않고 안내 문구만 표시합니다.
5. `runserver.bat`을 더블클릭해 서버를 실행합니다. 창을 닫거나 `Ctrl+C`를 누르면 서버가 종료됩니다.
6. 브라우저에서 `http://127.0.0.1:3000`에 접속합니다.
7. `runserver.bat`에 지정한 관리자 아이디/비밀번호로 로그인합니다. 기본 아이디는 `admin`입니다.

**관리자 화면(로그인·편집·결과)은 서버 PC에서만 열립니다.** 다른 PC·태블릿·휴대폰에서는 설문 응답 페이지만 열리고, 관리자 주소로 들어오면 "서버 PC 전용 화면" 안내가 표시됩니다.

인터넷에서 받은 파일이라 Windows 보안 경고가 표시될 수 있습니다. 이 경우 **추가 정보 → 실행**을 선택합니다.

## 3. 같은 네트워크에서 휴대폰/다른 PC로 시험하기

`runserver.bat`의 기본 `HOST`는 `0.0.0.0`입니다. 서버가 PC의 내부 IPv4 주소를 자동으로 찾아 설문 링크와 QR 코드에 사용합니다(대시보드 상단 **공유 주소**에 표시). 같은 Wi-Fi의 휴대폰으로 QR을 스캔하거나 링크를 열면 됩니다. 처음 실행할 때 Windows 방화벽 허용 창이 뜨면 **개인 네트워크**를 허용하세요.

- `HOST`를 `127.0.0.1`로 바꾸면 설문 링크·QR도 서버 PC에서만 열립니다.
- 응답자용 Wi-Fi가 따로 있으면 `WIFI_SSID`·`WIFI_PASSWORD`를 적어 두세요. 인쇄 페이지에 Wi-Fi 연결 QR이 함께 들어갑니다. 한글이 들어간 Wi-Fi 이름은 배치 파일에서 깨질 수 있으니 영문 이름을 권장합니다.
- 서버 PC가 병원 내부망에 연결되어 있다면 이 PC의 모바일 핫스팟이나 내부망 Wi-Fi에 환자 휴대폰을 연결하지 마세요. 환자 휴대폰은 오프라인 QR(4-1), 병원 태블릿은 태블릿(키오스크) 링크를 권장합니다. 자세한 검토는 `docs/NETWORK_PLAN.md`에 있습니다.
- PC에 VPN·가상 네트워크 어댑터가 있어 다른 주소가 잡히면, `HOST`에 Wi-Fi의 IPv4 주소(예: `192.168.0.12`)를 직접 적으세요.

**주의:** 이 MVP는 HTTPS, CSRF 방어, 영구 세션 저장, 요청 속도 제한, 다중 관리자, 감사 로그를 완비한 상용 서비스가 아닙니다. 포트 포워딩이나 인터넷 전체 공개를 하지 마세요. LAN 시험도 신뢰할 수 있는 네트워크에서만 하세요.

## 4. 현재 기능

- 관리자 로그인 (프로세스 메모리 세션, HttpOnly/SameSite 쿠키)
- 설문 생성, 제목·설명 편집, 질문 편집(드래그·방향키·화살표 버튼으로 순서 이동, 복제, 삭제), 응답자 화면 미리보기, 게시/종료
- 단답형, 장문형, 객관식, 복수 선택, 드롭다운, 점수형(1~5)
- 설문별 무작위 공개 링크와 QR 코드 (링크 복사, QR 이미지 PNG 저장)
- 응답 방식 (프로토타입, 아래 4-1 참고): 링크 QR / 태블릿(키오스크) / 오프라인 QR(응답 QR 전달)
- 시연 모드 (아래 4-2 참고): 서버 PC 한 대에서 QR 없이 생성 → 작성 → 확인을 창 3개로 확인
- 새 설문의 **진료 전 문진 예시** (성함·증상·복용 약 등 9개 질문과 동의 안내)
- 응답 전 동의 안내: 설문 편집 화면에 안내 문구를 입력하면 응답자가 동의해야 응답할 수 있음
- 진료실 비치용 A4 인쇄 페이지: 공유 창의 **진료실 비치용 인쇄 페이지** (설정 시 Wi-Fi 연결 QR 포함)
- 응답 정리: 결과 화면의 **응답 정리**로 기준 날짜 이전 응답 또는 전체 응답 삭제
- 관리자 화면은 서버 PC에서만 열림, 기본 비밀번호로는 실행되지 않음
- 비로그인 응답 제출 및 필수 항목 검증
- 전체 설문/응답 대시보드
- 질문별 집계 (선택지별 응답 수·비율, 점수형 평균, 주관식 최근 응답)
- 개별 응답 조회 (검색, 이전/다음 이동)
- CSV 내보내기 (엑셀 수식 실행 방지 처리)
- 로컬 JSON 데이터 파일

### 4-1. 응답 방식 (프로토타입)

설문 공유 창(대시보드의 QR, 설문 편집 화면의 공유 카드)에서 **링크 QR / 태블릿 / 오프라인 QR**을 전환할 수 있습니다.

| | 링크 QR | 태블릿(키오스크) | 오프라인 QR |
|---|---|---|---|
| 응답 기기 | 서버 PC와 같은 네트워크의 휴대폰 | 같은 네트워크의 병원 태블릿 | 환자 휴대폰 (설문 페이지만 열리면 됨) |
| 응답 저장 | 제출 즉시 서버에 저장 | 제출 즉시 서버에 저장 | 휴대폰에 **응답 QR** 표시 → 접수처에서 스캔해 저장 |
| 응답 전송 | 네트워크로 서버에 전송 | 네트워크로 서버에 전송 | 네트워크로 전송하지 않음 (화면의 QR로만 전달) |

태블릿(키오스크) 링크는 주소 끝에 `?kiosk=1`이 붙습니다. 응답을 제출하면 8초 뒤, 입력 도중 2분간 조작이 없으면 바로 처음 화면으로 돌아가 다음 환자가 이전 응답을 볼 수 없습니다. 태블릿은 화면 고정(안드로이드 "앱 고정", 아이패드 "사용법 유도")을 켜 두세요.

오프라인 QR 사용 순서:

1. 설문을 게시한 뒤 공유 창에서 **오프라인 QR**을 선택하고 **QR 이미지 저장**으로 인쇄용 이미지를 받아 비치합니다. 질문 내용이 QR 안에 들어가므로 화면보다 인쇄물로 스캔하는 것을 권장합니다.
2. 환자가 QR을 스캔해 응답하면 휴대폰에 응답 QR이 표시됩니다.
3. 서버 PC에서 **응답 QR 스캔**(대시보드·결과 화면)을 눌러 웹캠에 응답 QR을 비추면 저장됩니다. 이미지 파일에서 읽기, QR 스캐너·직접 입력도 지원합니다.

- 웹캠은 브라우저 보안 정책상 **서버 PC에서 `http://127.0.0.1:3000`으로 접속했을 때만** 사용할 수 있습니다.
- 오프라인 설문 페이지(`public/offline.html`)는 서버에 요청을 보내지 않습니다. 프로토타입에서는 이 서버가 페이지를 제공하므로 같은 Wi-Fi가 필요하지만, `offline.html`, `offline.js`, `shared.js`, `styles.css`, `vendor/qrcode.js`를 정적 호스팅에 올리면 LTE에서도 열 수 있습니다(설문 질문은 주소의 `#` 뒤에 있어 호스팅 서버로 전송되지 않음).
- 오프라인 QR을 비치한 뒤 질문을 바꾸면 이전 QR로 만든 응답은 저장이 거부됩니다. 새 QR을 비치하세요.
- 주관식 답변은 응답 QR 크기 때문에 질문당 200자까지 입력됩니다.

### 4-2. 시연 모드 (서버 PC 한 대, QR 없이)

대시보드의 **시연 모드**(`/demo`)에서 설문을 고르고 단계별 버튼으로 창을 엽니다.

1. **① 편집 창 열기**: 설문 편집 화면이 왼쪽 창으로 열립니다. 질문을 확인하고 **저장하고 게시하기**를 누릅니다. 새 설문을 **진료 전 문진 예시**로 만들면 기본 문진 질문이 들어 있습니다.
2. **② 응답 창 열기**: 환자 화면이 가운데에 휴대폰 크기 창으로 열립니다(태블릿 모드라 제출 8초 뒤 처음 화면으로 돌아감). 게시 전에는 열 수 없습니다.
3. **③ 결과 창 열기**: 결과 화면이 오른쪽 창으로 열리며 환자별 개별 응답부터 보여줍니다. ② 창에서 제출하면 새로고침 없이 바로 반영됩니다.

- 각 창 위쪽의 **시연** 표시줄로 어느 단계 창인지 구분합니다. 같은 버튼을 다시 누르면 이미 열린 창으로 이동합니다.
- 브라우저가 팝업을 막으면 주소창 오른쪽의 팝업 차단 아이콘에서 이 주소를 허용하세요.
- 자동 반영은 같은 PC의 같은 브라우저에서 연 창끼리만 동작합니다. 다른 기기에서 제출한 응답은 결과 화면을 새로고침하면 보입니다.

## 5. 데이터와 백업

모든 데이터는 `data/db.json`에 저장됩니다. 서버를 중지한 뒤 파일을 다른 위치로 복사해 백업하세요. 복구할 때는 서버를 중지하고 백업 파일을 `data/db.json`으로 되돌립니다.

보관 기간이 지난 응답은 결과 화면의 **응답 정리**로 삭제합니다(기준 날짜 0시 이전 또는 전체). 삭제 전에 CSV로 내보내 두세요. 응답이 모두 삭제되면 질문 구성 잠금도 풀립니다.

응답에는 민감한 정보가 들어갈 수 있으므로, 서버 PC에는 Windows의 BitLocker(Pro 이상) 같은 디스크 암호화를 켜 두는 것을 권장합니다.

새 버전의 압축파일을 받아 다른 폴더에 풀었다면, 기존 폴더의 `data` 폴더를 새 폴더로 복사해야 기존 설문과 응답이 유지됩니다.

설문 삭제는 해당 설문의 응답까지 삭제합니다. 삭제 전에 백업하세요.

## 6. MVP 제한사항

- 설문에 응답이 접수된 뒤에는 질문 구조를 잠급니다. 제목·설명은 수정할 수 있습니다. 질문 버전 관리는 다음 개발 단계에서 구현해야 합니다.
- 동일 응답자의 중복 제출을 완벽하게 막지 않습니다. 로그인 없는 공개 설문에서 강한 중복 방지는 별도 설계가 필요합니다.
- 현재 세션은 서버 재시작 시 만료됩니다.
- JSON 파일 저장은 동시 쓰기·대량 응답에 적합하지 않습니다. 외부 공개 운영 전에는 트랜잭션이 있는 데이터베이스로 교체해야 합니다.
- 비밀번호 변경은 실행 환경변수로 관리합니다.
- 통계는 선택형 문항 중심이며 주관식은 개별 원문에서 확인합니다.
